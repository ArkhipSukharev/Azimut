# Azimut

Клиент VPN для Windows: туннель WireGuard / AmneziaWG, генерация WARP и обход блокировок Discord и YouTube.

Версия программы задаётся в коде (`azimut/__init__.py`) и сейчас **1.6.0**. Python на компьютере **не нужен**. Достаточно Windows 10 или 11, 64-бит.

## Как установить

Скачайте **`Azimut-Setup-1.6.0.exe`**, откройте его и нажмите «Далее». Python на компьютере не нужен.

Установщик положит программу в «Program Files», создаст ярлык на рабочем столе и в меню «Пуск». Windows спросит права администратора — это нужно для туннеля и обхода. Разрешите.

Удаляется Azimut обычным способом: Параметры Windows → Приложения.

Если антивирус удаляет файлы, добавьте всю папку Azimut в исключения. Движок обхода использует драйвер WinDivert — многие антивирусы его не любят.

## Как пользоваться

1. На первом запуске можно сразу включить обход YouTube и Discord — готовый VPN для этого не нужен. Либо создать свой туннель.
2. Профиль туннеля: «Создать WARP» или «Импорт» файла `.conf` (WireGuard / AmneziaWG).
3. Кнопка по центру включает туннель. Если в настройках включено сворачивание к часам, закрытие окна сеть не выключает. Полный выход — пункт «Выход» у часов. На главной есть кнопка «Вернуть обычный интернет».

## Обновления из закрытого GitHub

Программа сама спрашивает GitHub, есть ли новый **Release** (не просто новый коммит). Если версия выше текущей, на главной появляется плашка «Установить обновление».

Закрытый репозиторий: `ArkhipSukharev/Azimut`. В настройках программы он уже указан. Нужен личный токен GitHub только на чтение. Токен хранится на этом компьютере под защитой Windows, не в открытом `settings.json`.

В релиз кладите файлы `Azimut-Setup-x.x.x.exe`, `Azimut-x.x.x.zip` и **`SHA256SUMS`** с контрольными суммами этих файлов. Без файла сумм программа обновление не поставит. Тег называйте как версию, например `v1.6.0`.

Нужен Python 3.11 или новее:

```
python -m pip install -r requirements.txt
python build.py
python make_installer.py
```

Готовый установщик появится в `dist\Azimut-Setup-1.6.0.exe`, рядом будет `SHA256SUMS`.
