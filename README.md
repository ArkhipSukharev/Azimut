# Azimut

**Дисклеймер.** Проект создан как некоммерческий и обучающий. Это учебная программа, а не коммерческий продукт.

Клиент VPN для Windows: туннель WireGuard / AmneziaWG, генерация WARP и обход блокировок Discord и YouTube.

Версия программы задаётся в коде (`azimut/__init__.py`) и сейчас **1.7.2**. Python на компьютере **не нужен**. Достаточно Windows 10 или 11, 64-бит.

## Как установить

Скачайте **`Azimut-Setup-1.7.2.exe`** из [выпуска](https://github.com/ArkhipSukharev/Azimut/releases/tag/v1.7.2), откройте его и нажмите «Далее». Python на компьютере не нужен.

Установщик кладёт программу в «Program Files», создаёт ярлык в меню «Пуск» и — если не сняли галочку — один ярлык на рабочем столе. После первого запуска второй ярлык программа **не создаёт**. Windows спросит права администратора — это нужно для туннеля и обхода. Разрешите.

Можно без установщика: скачайте **`Azimut-1.7.2.zip`** из [того же выпуска](https://github.com/ArkhipSukharev/Azimut/releases/tag/v1.7.2), распакуйте папку целиком и откройте `Azimut.exe`. Файл из папки не вытаскивайте: рядом должны остаться `engine`, `zapret` и `assets`.

Удаляется Azimut обычным способом: Параметры Windows → Приложения.

Если антивирус удаляет файлы, добавьте всю папку Azimut в исключения. Движок обхода использует драйвер WinDivert — многие антивирусы его не любят. В настройках программы есть кнопка «Проверить файлы обхода» — она назовёт пропавший файл.

## Как пользоваться

1. На первом запуске можно сразу включить обход YouTube и Discord — готовый VPN для этого не нужен. Либо создать свой туннель. При каждом открытии и затем каждые несколько часов Azimut сам смотрит официальные GitHub zapret и GoodbyeDPI и подтягивает более новую сборку. Включение обхода идёт без полноэкранного ожидания: движок просто запускается, статус виден на главной. Если новая сборка хуже, на главной есть кнопка «Вернуть прежний». Пока программа работает, она периодически проверяет YouTube и Discord и при необходимости подбирает другой способ.
2. В режиме **«Сайты и программы»** через туннель идут отмеченные сервисы (страница «Сайты») и выбранные программы Windows (страница «Программы»). Программа смотрит, к каким адресам ходит выбранное приложение, запоминает их и пускает через туннель. Первые секунды после добавления нового приложения адреса ещё могут идти напрямую. На WARP, который создал сам Azimut, этот режим недоступен: такой профиль всегда пускает весь интернет.
3. Профиль туннеля: «Создать WARP» или «Импорт» файла `.conf` (WireGuard / AmneziaWG).
4. Кнопка по центру включает туннель. Смена сайтов, программ или обхода пересобирает туннель сама. Страница «Проверка» показывает, должен ли сайт идти через туннель по списку и открывается ли он сейчас именно через туннель. Если в настройках включено сворачивание к часам, закрытие окна сеть не выключает. Полный выход — пункт «Выход» у часов.

## Обновления из GitHub

Программа сама спрашивает GitHub, есть ли новый **Release** (не просто новый коммит). Если версия выше текущей, на главной появляется плашка «Установить обновление».

Репозиторий открытый: https://github.com/ArkhipSukharev/Azimut  
Для установки достаточно скачать файл из выпуска. Личный токен GitHub в настройках не обязателен; если его указать (только чтение), программе проще обходить лимиты GitHub. Токен хранится на этом компьютере под защитой Windows, не в открытом `settings.json`.

В релиз кладите файлы `Azimut-Setup-x.x.x.exe`, `Azimut-x.x.x.zip` и **`SHA256SUMS`** с контрольными суммами этих файлов. Без файла сумм программа обновление не поставит. Тег называйте как версию, например `v1.7.2`.

## Сборка из исходников

Нужен Python 3.11 или новее:

```
python -m pip install -r requirements.txt
python build.py
python make_installer.py
```

Готовый установщик появится в `dist\Azimut-Setup-1.7.2.exe`, рядом будут zip и `SHA256SUMS`. Установщик берёт свежую сборку из `dist\Azimut`.
